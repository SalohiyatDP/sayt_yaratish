# Demo (namuna) kontent

Bu katalogdagi fayllar **namunaviy ma'lumotlar** bo'lib, saytning imkoniyatlarini
ko'rsatish uchun tayyorlangan. Ular haqiqiy hududlar, lotlar, maydonlar, narxlar,
sanalar yoki voqealarni aks ettirmaydi.

## Ular saytga qanday tushadi

- Odatiy qurishda (`npm run build`) bu fayllar **umuman o'qilmaydi**.
  Sayt bo'sh holatlar bilan chiqadi: «Ma'lumot hozircha joylashtirilmagan».
- Demo qurishda (`npm run build:demo`) ular qo'shiladi va har bir yozuv
  **«DEMO» nishoni** bilan, saytning yuqorisida esa ogohlantirish banneri bilan
  ko'rsatiladi.

## Nima uchun kerak

Ishga topshirishdan oldin buyurtmachi saralash, xarita, lot passporti,
master-reja ko'ruvchisi va taqqoslash savati kabi funksiyalarni haqiqiy
ma'lumot kiritmasdan sinab ko'ra oladi.

## ⚠️ Muhim

Ishlab turgan (produksiya) saytni **hech qachon** demo rejimida qurmang.
Namunaviy ma'lumotni haqiqiy deb ko'rsatish man etiladi. Haqiqiy kontent
kiritilgach, bu katalogni o'chirib tashlashingiz mumkin.

## Nomlar haqida

Namunadagi hudud nomlari ataylab umumiy tanlangan («Namuna hudud 1» va h.k.) —
mavjud bo'lmagan joy nomlari o'ylab chiqarilmagan. Koordinatalar Namangan
viloyati doirasidagi shartli nuqtalar bo'lib, hech qanday aniq yer
uchastkasiga taalluqli emas.
